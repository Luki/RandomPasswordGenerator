How Password Strength Is Evaluated

This tester weighs password length, character variety, common words, repeated and sequential patterns, and comparisons with the loaded local common-password list. A partial list match is not a verdict by itself. It does not check breached-password databases or estimate cracking time, so a high score cannot prove that a password is secure.

What Makes a Password Strong?

Long, random, and unique passwords are generally harder to guess. Avoid familiar words, names, dates, and predictable substitutions. A passphrase can work well when it uses several randomly selected, unrelated words; familiar sayings and lyrics are predictable. Spaces count toward length but are not symbols, and some websites do not allow them.

How to Improve a Weak Password

Make it longer, avoid predictable sequences, and use a unique password for every account. A password manager can make unique passwords easier to manage.

Why Password Length Matters

Every additional character increases the number of possible combinations. A longer password is especially helpful when it is generated randomly rather than built from a familiar phrase.
